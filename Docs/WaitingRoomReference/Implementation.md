## 연결한 기능

| 항목 | 동작 |
|---|---|
| 준비 | 본인 준비 완료/취소를 서버에 전송, 모든 카드 동기화 |
| 탐사 시작 | 호스트만 표시, 기존 규칙인 최소 4명 및 전원 준비 시 활성화 |
| 나가기 | 연결 종료 후 탐사 로비로 복귀 |
| 카드 수 | 실제 접속 인원 1~6명에 맞춰 재배치 |
| 음성 아이콘 | 해당 플레이어의 마이크 활성 상태. 발화 음량 표시가 아님 |
| 채팅 | Enter 또는 전송 버튼, 최대 120자, 최근 24개, 서버 기준 0.75초 전송 제한 |
| 채팅 방어 | 서버에서 발신자/이름 결정, 제어문자 제거, 빈 내용/길이 초과/미접속 발신자 거부, 리치텍스트 비활성화 |
| 설정 | 우측 상단 반투명 톱니바퀴 또는 ESC로 열기/닫기. 호스트 산소 예산, 로컬 마이크/수신 음소거, 기존 기록 보관소 |
| 참가 코드 | 호스트 지역 패널에 표시하고 클릭하여 복사 |
| 버튼 | 흰 띠 오버레이 대신 전체 높이의 반투명 그라데이션. 호버/키보드 선택 시 표시, 누를 때 강화. 준비 완료/시작 배경에 박힌 흰 띠 부분도 제외 |

네트워크 프로토콜은 7이다. 참가자 모두 같은 최신 빌드를 사용해야 한다. 연결 범위는 기존에 승인된 LAN이며 인터넷 중계 서비스는 추가하지 않았다.

## 검증 범위

- EditMode: 1~6명 좌표/겹침, 채팅 발신자/길이/빈 내용/전송 제한/보관 수, 음성 상태 및 기존 게임 회귀 테스트.
- PlayMode: 기존 게임/네트워크 회귀 테스트. 그래픽 장치가 없는 실행에서는 초상화 렌더링을 생략한다.
- Windows 실행: 실제 로컬 NGO/UDP 연결로 6명 입장, 준비/취소, 채팅, 마이크 상태, 탐사 시작, 클라이언트 시작 버튼 숨김, 호스트 이탈을 검증한다.
- 화면 검증: 1672x941, 1280x720, 1920x1080, 1024x768. 초상화 픽셀 비어 있지 않음 검사 포함.
- 같은 PC의 실제 네트워크 세션으로 검증하며 서로 다른 물리 PC 사이의 방화벽/공유기 조건은 검증하지 않았다.
- 최종 실행 경로는 `Builds/Latest/EarthRecovery.exe`. 이전 빌드는 두 개만 보관한다.

최신 검증 결과: EditMode 80개, PlayMode 34개 통과. 기본 지역이 아닌 테스트 지역의 광고·참가·복귀 동기화 포함. 실행 화면 검사 대기실 118개, 로비 23개 통과. 자료는 `QA/Waiting-region-EditMode.xml`, `QA/Waiting-region-PlayMode.xml`, `QA/Waiting-region-Waiting`, `QA/Waiting-region-Lobby`에 보관한다. 기존 타이틀 검사 자료는 `QA/Waiting-final-Title`에 남겨두었다.
