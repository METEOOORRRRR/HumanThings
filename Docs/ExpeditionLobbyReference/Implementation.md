## 동작

- 방 생성: 이름 1~20자, 인원 4~6명, 공개/비공개, 선택적 비밀번호 최대 6자. 요원명 입력을 유지했다.
- 탐사 구역은 실제 구현된 서울 하나만 표시한다. 레퍼런스의 부산/제주 등은 예시이므로 추가하지 않았다.
- 공개 방은 UDP 질의에 실제 응답한 호스트만 표시한다. 레퍼런스의 가상 방 목록은 사용하지 않는다.
- 2초 간격으로 검색하고 6초 동안 응답이 없는 방을 목록에서 제거한다. 비공개 방은 공개 검색에 응답하지 않는다.
- 참가 코드는 4자리씩 4칸이다. 코드 전체 붙여넣기를 지원하며 잘못된 형식과 응답 없는 방을 구분해 표시한다.
- 비밀번호는 서버 승인 단계에서 확인한다. 새로 생성된 방은 다른 ID를 사용하므로 이전 방 정보로 직접 접속하면 거절한다.
- 탐사 중이거나 정원이 찬 방의 참가 버튼은 비활성화한다. 서버에서도 정원과 상태를 다시 확인한다.
- 접속 중 중복 작업과 메뉴 전환을 막고 취소를 제공한다. 방 종료/연결 해제 시 준비 화면을 제거한다.
- 기존 준비/탐사 시작/나가기, 호스트 산소 예산 조절, 마이크 선택적 활성화, 수신 음소거, 기록 보관소 기능을 대기실에 유지했다.

## LAN 범위와 제한

사용자 확인에 따라 이번 구현은 같은 네트워크 기준이다. 인터넷 중계, 계정, 외부 로비 서버, NAT 통과 서비스는 추가하지 않았다.

- 게임 UDP 포트: 7777~7784 중 사용 가능한 포트. 검색 포트는 해당 포트 + 30000.
- 여러 PC에서 사용할 때 Windows 방화벽의 개인 네트워크 허용 및 공유기의 클라이언트 격리 설정에 영향을 받는다. 방화벽 설정을 자동 변경하지 않았다.
- 동일 PC 다중 실행도 루프백 검색으로 지원한다.
- 여러 네트워크 어댑터가 있으면 참가 코드의 주소는 활성 어댑터의 게이트웨이를 우선해 선택한다. 다른 어댑터에 연결된 사용자는 공개 검색을 이용하거나 네트워크 구성을 확인해야 한다.
- 비밀번호 원문 대신 방 ID에 연결된 해시를 승인 데이터로 보내지만, LAN 프로토타입은 암호화된 인터넷 인증 서비스가 아니다. 비밀번호 기능을 강한 보안 경계로 간주하지 않는다.
- 레퍼런스의 완성 이미지에서 UI를 제거한 배경에는 원본 인페인팅 흔적이 남아 있다. 제공 이미지는 수정하지 않았고 노이즈 투명도 및 패널 명암만 조절했다.

## 검증

최종 결과: EditMode 60개, PlayMode 33개, 로비 화면 23개, 타이틀 회귀 화면 45개 통과. 최종 캡처는 `QA/Lobby-final`, 타이틀 캡처는 `QA/Lobby-title-final`에 보관했다.

- `QA/Lobby-EditMode.xml`: 기존 테스트와 코드 형식/메타데이터/비밀번호 해시 검증.
- `QA/Lobby-PlayMode.xml`: 기존 게임 테스트, 실제 UDP 공개 검색, 비공개 코드 검색, 비밀번호 거절 후 정상 재접속, 호스트 종료, 이전 방 ID 거절.
- 개발 빌드 `--lobby-qa`: 실제 호스트를 생성하여 공개 목록을 채우고, 마우스 입력으로 패널 전환/선택/생성/나가기/뒤로를 확인한다. 화면 좌표, 없는 방의 준비 UI 차단, 코드 붙여넣기와 해상도도 검사한다.
- 테스트는 한 PC의 실제 UDP 호스트/클라이언트로 진행했다. 별도 두 PC 사이의 물리 LAN 환경은 여기서 검증하지 않았다.
- 최신 실행 파일은 `Builds/Latest/EarthRecovery.exe`이며 이전 공개 빌드는 두 개만 보관한다.
