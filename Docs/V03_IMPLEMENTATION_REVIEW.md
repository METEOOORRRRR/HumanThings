## 명시적으로 남긴 통합 항목

1. **주파수·압력밸브 퍼즐 상세 규칙**: 6.3은 기존 퍼즐 재사용을 요구하지만 이전 프로젝트에는 회전·인형뽑기·미로만 존재한다. 상세 조작·성공·실패 규칙을 임의로 새로 확정하지 않았다. 현재 콘텐츠는 구현된 3종의 PuzzleProfile을 사용한다. 새 2종의 규칙 확정 후 프로필 실행기를 확장해야 한다.
2. **M05 실제 오염 공급원**: 이전 구현에는 필터 소모나 생존 중 오염 누적이 없다. 17절에 따라 `IPollutionProvider`만 연결하고 기본 공급원은 0이다. 위험도 공급 시 추적이 바뀌는 테스트는 통과하도록 구현했다. 필터 게임 규칙은 새로 만들지 않았다.
3. **실시간 AI 음성 합성**: 필수 아님. `IVoiceMimicSource`와 기존 무전의 최대 1초 RAM 버퍼, Windows 한국어 TTS로 생성한 생활 문장 3개를 사용한다. 플레이어 음성을 파일로 저장하거나 외부로 업로드하지 않는다.
4. **구체 아트·애니메이션**: 사용자 요청대로 기본 도형 프리팹을 사용한다. 인간 흔적은 이동·정지·자세·음성으로 표현하며 완성 캐릭터 아트가 아니다.

## 운영상 선택과 주의

- 기본 시작 인원은 새 명세대로 4명, 최대 6명. 자동 테스트에서만 2인 설정을 허용한다.
- Archive는 해당 호스트 PC의 공유 도감이다. 클라이언트에는 호스트 도감을 동기화한다. 계정별 클라우드 동기화나 플랫폼 저장은 구현 범위 밖이다.
- 저장 위치: `Application.persistentDataPath/human-things-archive-v1.json`. 임시 파일을 원본과 교체하며 `.bak`으로 복구한다.
- 관찰만 등록된 항목은 물건 실명을 먼저 공개하지 않는다. 괴물이 인간이었다는 문구도 직접 표시하지 않는다.
- 명세의 연구 구역 장소 ID `RES_HOSPITAL`, `RES_LAB`, `RES_SIGNAL_STATION`은 접두사와 관계없이 원문 그대로 보존했고 실제 zone은 Research로 연결했다.
- `Tools/import_v03.py`는 문서 표의 한국어 콘텐츠를 그대로 추출한다. 영어 이름은 구현용 번역이다. 한 개뿐인 단서는 33/66% 슬롯에 재사용되며 새로운 사실을 임의로 추가하지 않았다.
- `HumanContentBuilder.Build`는 콘텐츠를 명세 기준으로 재생성하는 명시적 도구다. 수동으로 튜닝한 자산을 보존하려면 다시 실행하지 않는다. 일반 빌드는 기존 콘텐츠 자산이 있으면 재생성하지 않는다.
- 장거리 인터넷/지연 환경, 실제 마이크 장치 분리, 4~6명의 사람을 통한 재미·난이도·단서 가독성은 별도 수동 검수 항목이다.

- 최신 실행 파일: `Builds/Windows-HumanThings-v03/EarthRecovery.exe`. 기존 빌드는 보존했다.
