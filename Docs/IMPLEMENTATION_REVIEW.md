기준: `지구_회수_요원_게임기획안_GDD_재작성본.pdf` v0.2 및 대화에서 사용자가 채택한 수정사항. 기존 PDF는 수정하지 않았습니다.

## 확정 기획이 아닌 검증값

다음 값은 핵심 루프를 실행하기 위한 교체 가능한 기본값입니다. 최종 기획으로 확정한 것이 아닙니다.

| 항목 | 임시값 |
|---|---|
| 시작 가능 인원 | 2명 이상, 최대 6명 |
| 산소 | 기본 20분, 대기실에서 5~29분 조절 |
| 맵 | 약 150m × 150m, 제작소 10개 |
| 가방 | 재료 합계 12개, 완성품 1개 별도 |
| 제품 요구 레벨 | 각 장소의 제품을 1~3단계에 배정 |
| 단계별 업그레이드 | 해당 단계 전용 재료 2개 |
| 제작 | 성공 4회, 2.4초 판정 주기 |
| 이동 | 걷기 4, 달리기 6, 운반 3 m/s |
| 괴물 | 4종 총 8개, 접촉 시 즉시 사망 |
| 정지 감지 | 외부에서 12초 정지 |
| 음성 | 8 kHz 무전 품질, 기본 꺼짐, V PTT |

`GameRules.asset`의 수치와 카탈로그를 통해 조절합니다. QA 자동 실행은 별도 검증을 위해 이동 속도를 올리고 괴물을 제거합니다. 이 조건을 일반 게임의 난이도·성능 검증 결과로 해석하지 않습니다.

## 검토 순서

1. 두 실행 파일로 제작소 관측/캠프 조작의 소통이 재미있는지 확인합니다.
2. Q01 시점, Q02 필터, Q03 음성 합성 방식을 우선 결정합니다.
3. 실제 4~6인으로 이동 거리·재료량·세션 길이를 측정한 뒤 수치를 조절합니다.

검증 결과와 실행 중 발견한 제약은 `VERIFICATION.md`에 별도로 기록합니다.
