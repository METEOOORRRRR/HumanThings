# 호출벨 제거

사용자가 승인한 범위: 호출벨 기능 제거. 접속 대기 UI 및 사용자가 실행 중인 화면의 장소명 불일치 조사/수정과 별개다.

- 시설 프리팹 4곳의 CounterBell 오브젝트 및 자식 기본 도형 삭제.
- 월드의 호출벨 안내 문구와 E 상호작용 삭제.
- 서버의 bell 명령 처리, Bell 소음 이벤트 삭제.
- 대기자 괴물의 BellLook 반응 삭제. 기존 순찰과 정지 감지, 기억 행동은 유지.
- 콘텐츠 재생성기에서도 호출벨 목록 제거. 자산 재생성 시 다시 추가되지 않음.
- 조작 문서의 호출벨 항목 삭제. 이전 버전 검토 기록은 이력으로 보존.

검증 로그는 QA/NoBell-*에 기록한다. 호출벨 없는 시설 프리팹 검사와 구형 bell 명령 무효화 회귀 테스트를 추가했다.

결과: EditMode 52개, PlayMode 26개 모두 통과. Windows 빌드 Succeeded, errors=0. 런타임 소스/시설 프리팹/콘텐츠 생성기에서 호출벨 관련 참조가 남아 있지 않음을 검색 확인했다. 별도의 6인 실행 파일 통합 테스트는 이번 제거 작업에서 재실행하지 않았다.

실행 파일: Builds/Windows-HumanThings-v03-NoBell/EarthRecovery.exe. 이전 빌드는 보존하며 새 빌드로 확인한다.
