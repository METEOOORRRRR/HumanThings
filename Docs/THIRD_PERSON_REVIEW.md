# 3인칭 시점 반영 검토

사용자 확정 사항: 플레이어 시점은 3인칭. 기존 v0.3 빌드는 보존한다.

## 반영

- 자기 캐릭터 렌더링 활성화, 몸체 기준 높이 1.45m / 뒤쪽 3.6m 카메라.
- 기본 내려보기 18도, 마우스 상하 범위 -30~65도. 기존 시점 기준 이동과 서버 이동 권한 유지.
- 환경 레이어에 구체 충돌 검사 적용. 벽/바닥 앞에서 즉시 거리 축소, 회수 영역 등의 트리거는 무시.
- 생존자 관전에도 동일한 충돌 처리 적용. 앱 포커스가 없으면 마우스 시점 입력 무시.

## 검증

- QA/ThirdPerson-PlayMode.xml: 23개 통과, 실패 0. 기존 회귀 테스트 및 신규 카메라 테스트 4개 포함.
- 신규 테스트: 로컬 모델/카메라 방향, 트리거 무시/벽 충돌, 캠프 벽 근접 및 상하 각도별 바닥 충돌, 사망 후 관전.
- QA/ThirdPerson-build.log: Windows 빌드 성공.
- QA/ThirdPerson-six: 실제 실행 파일 6개 모두 PASS 및 정상 종료. 모듈 제작, 설치, 협동 퍼즐, 물건 3개 회수, 도감 등록 확인.
- camp-world.png와 field-1-world.png를 직접 열어 로컬 캐릭터 표시 및 실내 3인칭 구도 확인. Camera.Render 캡처이므로 IMGUI 배치 검증 결과로 사용하지 않음.

## 실행 파일

Builds/Windows-HumanThings-v03-ThirdPerson/EarthRecovery.exe

카메라 조작감은 자동 검사와 별도로 실제 플레이에서 거리/감도를 조정할 수 있다. 극단적으로 벽과 밀착하면 카메라가 캐릭터 가까이 당겨진다.
