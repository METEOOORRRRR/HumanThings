# Revision1 승인 수정안 검토

기준: 사용자 승인한 장소명, 임무 정보 공개, 전체 모듈 선택, 지도, 시설 단말기, 괴물 순찰 수정안. 기존 문서와 이전 실행 파일은 보존한다.

## 장소명

| 구역 | 시설 1 | 시설 2 | 시설 3 |
|---|---|---|---|
| 상업구역 | 악기점 | 식당 | 전자상가 |
| 주거구역 | 문방구 | 의류점 | 편의점 |
| 산업구역 | 공구점 | 정비소 | 인쇄소 |
| 연구구역 | 병원 | 실험실 | 관측소 |
| 문화구역 | 도서관 | 학교 | 박물관 |

콘텐츠 원본 JSON과 실제 ScriptableObject 자산을 함께 변경했다. 각 시설은 자신의 구역 내 소켓에 생성되며 구역 간 이동은 없다. 문방구는 기존 장난감 가게의 명칭 변경이며, 승인 범위 밖인 물품 45종의 구성은 그대로 유지한다.

## 반영 내역

| 항목 | 구현 |
|---|---|
| 표본 신원 | 모든 미회수 임무는 표본 코드 / ???. 과거 도감 등록으로 현재 이름이 먼저 공개되지 않음 |
| 캠프 단말기 | 표본 3개, 각 진행 상태와 재질/분류/기능 단서, 협동 연결. 시설 정답 및 직접 구역 힌트 제외 |
| 복원 제작기 | 구역 탭 5개, 구역당 시설 모듈 3종. 임무 여부에 관계없이 서버에서 제작 허용. 임무 대상 강조 없음 |
| 제작기 외형 | 모든 제작기 주황색 통일. 시설 내부 단말기는 청록색으로 구분 |
| 지도 | 실제 소켓 범위를 덮는 구역별 색상 영역. 15개 시설 위치 항상 표시, 미발견 ?? / 발견 후 실제 이름 |
| 단말기 접근 | 시설 내부 큐브에서 수평 거리 2.5m 이내 E. 모듈/임무 여부와 관계없이 팝업 가능. 가까운 단말기 우선 |
| 복원 상태 | 미설치, 모듈 보유 여부, 설치 가능/불가, 설치 중, 복원 완료. 서버도 거리와 모듈을 검증 |
| 비임무 시설 | 모듈 제작/설치 가능. 복원 후 제작 요청 없음 표시, 임의 표본 제작은 허용하지 않음 |
| 괴물 기본 이동 | 출발점 분산, 일반 개체 랜덤 순찰, 통근자 경로 배회. 도착/시간 경과/경로 실패/정체 시 경로 갱신 |
| 괴물 안전장치 | NavMesh 위 완전한 순찰 경로만 선택, 벗어나면 복귀 시도, 이동 정체 3초 기준 재탐색. 기억 행동의 일시 정지 보존 |
| UI 겹침 | 팝업 뒤 임무창과 발견 알림 숨김, 불투명 패널, 보조 글자 대비 개선 |

기존 지식 유지 모드가 이름을 미리 보여주던 동작은 새 승인 규칙과 충돌하여 제거했다. 로비의 해당 전환 버튼도 제거했으며 저장된 도감은 삭제하지 않았다. 구형 설정 필드는 자산 호환을 위해 유지한다.

## 검증

- EditMode 50개 통과: 콘텐츠 관계/텍스트, 이름 15종, 소속 구역 좌표, 전체 모듈 제작/설치, 회수 전 신원 비공개, 시설 정답 없는 캠프 정보, 서버 접근 제한 등.
- PlayMode 26개 통과: 모듈 없는 시설 15개 팝업, 플레이어가 캠프에만 있을 때 괴물 6종 이동, 도달 불가능 목적지 복구, 기존 카메라/전송/세션 종료/괴물 반응 회귀 검사 등.
- 1차 실제 6인 실행 전원 PASS: 모듈 제작, 설치, 스킬체크, 협동 퍼즐, 물건 3개 운반/회수, 도감 3개 등록, 생존/사망 무전 분리.
- 실제 창 캡처로 캠프 지도/표본, 구역 선택, 설치 가능 상태를 확인하고 팝업 뒤 UI 잔상 문제를 추가 수정했다.

최종 빌드 재검증:

- QA/Revision1-build.log: BUILD_RESULT Succeeded errors=0.
- QA/Revision1-six-final: 6개 실행 파일 모두 PASS, 종료 코드 0. 런타임 Exception 및 QA_FAIL 없음.
- 최종 캠프 화면: 임무 3칸은 표본 정보만 표시. 미회수 ??? 유지, 회수 완료 물건만 이름 공개.
- 최종 지도: 미발견 15개 위치와 구역 색상 확인. 탐사 후 악기점/전자상가/공구점/실험실 이름 공개, 나머지 ?? 유지 확인.
- 최종 제작기 화면: 구역 탭과 시설별 모듈 목록, 주황색 기계 확인.
- 최종 비임무 악기점 화면: 모듈 없이 단말기 팝업 표시, 설치 불가/모듈 미보유 문구와 비활성 설치 버튼 확인.
- 이번 UI 검수는 사용자가 표시를 허용한 실제 테스트 창의 ScreenCapture 결과를 직접 열어서 수행했다. 숨김 실행에서 생성된 검은 UI 이미지는 검수 근거로 사용하지 않았다.
